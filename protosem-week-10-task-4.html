Arduino DHT11 Temperature & Humidity

← Week 10Task 1Task 2Task 3Task 4Task 5Task 6Task 7Task 8

01Overview

This task brings real sensor data into LabVIEW. An Arduino reads a DHT11 temperature and humidity sensor and sends the readings to the computer over a USB serial connection. The LabVIEW VI opens that serial port, reads the text the Arduino sends, picks the temperature and humidity out of it, and shows them on a thermometer and a tank.

The VI is Task3 arduino.vi in the Labview Assignment.lvproj project.

02Concepts

Serial communication

The Arduino sends data one character at a time over USB. Both sides must use the same baud rate, which is the speed of the connection.

VISA

The set of LabVIEW functions for talking to instruments and serial ports. The VISA resource name is the port the Arduino is plugged into, for example a COM port.

VISA Read

Reads up to a chosen byte count from the serial buffer and returns it as a text string, shown here as read buffer.

String Subset

Cuts a piece out of a string, given a starting position and a length. Here it separates the temperature and humidity numbers from the text line.

Shift register

Carries a value from one loop iteration to the next. The VISA connection and error wires use shift registers so the port stays open while the loop runs.

05Front Panel

The front panel has two groups of items at the top and a display area at the bottom. On the left are the connection settings: the VISA resource name, the baud rate and the STOP button. On the right are the reading settings and raw text: byte count, milliseconds to wait and the read buffer. The two small substring boxes sit above them. The large panel titled DHT11 DATA holds the Temperature thermometer and the Humidity tank.

06Block Diagram

The block diagram has a setup stage on the left, a While Loop in the middle and a clean-up stage on the right. Reading from left to right:

  1. The VISA resource name and baud rate are wired to VISA Configure Serial Port, which opens the port and sets its speed.
  2. The VISA connection and the error wire enter the While Loop through shift registers, so the port stays open on every iteration.
  3. Inside the loop, VISA Read reads up to byte count bytes and sends the text to the read buffer indicator.
  4. A Wait (ms) function, set by milliseconds to wait, paces the loop.
  5. Two String Subset functions cut the text. The first uses the constants 6 and 5 and feeds substring, and the second uses 25 and 5 and feeds substring 2.
  6. Each substring is converted from text to a number. The first number goes to Temperature and the second to Humidity.
  7. The STOP button is wired to the stop terminal. When the loop ends, VISA Close on the right closes the serial port.

07Configuration

  1. Upload the DHT11 sketch to the Arduino and leave it connected to the computer with the USB cable.
  2. Open Labview Assignment.lvproj and double-click Task3 arduino.vi.
  3. Choose the Arduino’s port in VISA resource name.
  4. Set baud rate to the same value used in the Arduino sketch.
  5. Set byte count large enough for one full line of text, and set milliseconds to wait.
  6. Click Run. The read buffer fills with text and the thermometer and tank follow the sensor.
  7. Click STOP to end the program and close the port.

09Observations

  • The controls must be set before running — in the screenshots the VISA resource name is empty and baud rate, byte count and wait time are all 0, which are the defaults. The port, a baud rate matching the Arduino, and sensible values for the other two have to be entered first.
  • The substring positions are fixed — the temperature is taken from position 6 and the humidity from position 25. This only works while the Arduino prints its text in exactly the same layout, so changing the sketch’s message would break the readings.
  • The scales do not match the sensor — the thermometer runs from 0 to 100, but a DHT11 only measures 0 to 50 °C. The humidity tank stops at 80, while a DHT11 can read higher than that.
  • The raw text is shown on screen — the read buffer and substring indicators make it easy to see what the Arduino is sending and to check that the cut positions are right.
  • There is no error indicator — the error wire is passed through the loop and into VISA Close, but it is not shown to the user, so a wrong port or baud rate fails quietly.

10Reflection

This task connects the earlier ideas to a real device: a While Loop with a STOP button, indicators for the output, and now a serial connection to hardware. Splitting the problem into open the port, read and parse the text, display the numbers, and close the port is a pattern that will repeat in the later sensor tasks.

11Project File

The VI is part of the Labview Assignment.lvproj project: Task3 arduino.vi.

Task 4 is also built as a standalone Windows application, Task4.exe (about 211 KB), so it can run without opening the LabVIEW project. It needs the LabVIEW Run-Time Engine (64-bit) and, because it uses VISA serial functions, the NI-VISA runtime, with the Arduino connected to its COM port. Windows may show a security warning because the file is not digitally signed.
