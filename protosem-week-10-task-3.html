Temperature Unit Switch & SubVI

← Week 10Task 1Task 2Task 3Task 4Task 5Task 6Task 7Task 8

01Overview

This task extends the temperature VI from Task 2. A Set Unit switch is added so the user can choose whether the boiler temperature is shown as it is (degrees Celsius) or converted to Fahrenheit. The conversion itself is moved out of the main program into a SubVI, a small reusable VI that is called like a single function.

The main VI is TASK 2 extended set temperature boiler temperature stop.vi and the SubVI is Untitled 2 (SubVI).vi.

02Concepts

SubVI

A VI used inside another VI, like a function. It has its own front panel and block diagram, an icon, and a connector pane that decides which controls and indicators become its input and output terminals.

Case Structure

Runs only one of its cases, chosen by the value wired to the ? selector. Here the selector is a Boolean, so there are two cases: True and False.

Boolean switch

A control with two states. The Set Unit switch decides which case of the SubVI runs.

Wait (ms)

Slows the While Loop down. With 100 ms the loop runs about ten times a second instead of as fast as the computer allows.

Execution highlighting

The light bulb button in the block diagram toolbar. It slows the program down and shows the value on every wire, which is useful for checking the maths.

05Main VI: Front Panel

The front panel is the Task 2 panel with one new item. The Set Temperature(°C) knob is on the left, the new Set Unit switch and the STOP button are in the middle, and the Boiler Temperature thermometer is on the right.

06Main VI: Block Diagram

The While Loop now contains a SubVI instead of the arithmetic from Task 2:

  1. The Set Temperature(°C) knob is wired to the SubVI input.
  2. The Set Unit switch is wired to the SubVI’s Boolean input.
  3. The SubVI output goes to the Boiler Temperature thermometer.
  4. A Wait (ms) function with the constant 100 slows the loop down.
  5. The stop button is wired to the stop terminal of the loop.

07The SubVI

The SubVI has two inputs and one output. Set Temperature(°C) in is the temperature, Set Unit is the Boolean, and Set Temperature(°C) out is the result. Its icon is a thermometer with a C, which is what appears in the main block diagram.

Inside, a Case Structure is controlled by the Set Unit Boolean:

  • True case: the input is multiplied by 9 ÷ 5 and 32 is added, which converts Celsius to Fahrenheit.
  • False case: the input is wired straight to the output, so the value stays in Celsius.

08Configuration

  1. Open Labview Assignment.lvproj and double-click TASK 2 extended set temperature boiler temperature stop.vi.
  2. Click the Run arrow in the toolbar.
  3. Turn the Set Temperature(°C) knob to a value between 0 and 10.
  4. Flip the Set Unit switch and watch the Boiler Temperature thermometer change.
  5. Click STOP to end the program.

To test the SubVI by itself, open Untitled 2 (SubVI).vi, type a value into Set Temperature(°C) in, set the switch and click Run.

10Observations

  • The SubVI still has a placeholder name — it is called Untitled 2 (SubVI).vi and its window shows an asterisk, which means it has unsaved changes. Saving it with a clear name such as Temperature Unit Convert.vi would make the project easier to read.
  • The labels do not change with the unit — the knob is always labelled °C and the thermometer has no unit, so nothing on screen says whether the reading is °C or °F.
  • The Wait (ms) of 100 fixes the Task 2 loop speed — Task 2 had no wait, so it ran as fast as the processor allowed.
  • The thermometer only reaches 50 — the knob stops at 10, so the highest Fahrenheit value is 50 and most of the 0 to 100 scale is unused.
  • Only one case does any maths — the False case simply passes the value through, which is the reason the SubVI works as a unit selector.

11Reflection

Moving the conversion into a SubVI keeps the main block diagram short and readable, and the same SubVI could be reused in any other VI that needs a temperature in a chosen unit. The Case Structure is a good example of a decision in LabVIEW: one Boolean value picks which block of code runs.
