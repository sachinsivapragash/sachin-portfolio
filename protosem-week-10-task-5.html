Waveform Chart Leveller

← Week 10Task 1Task 2Task 3Task 4Task 5Task 6Task 7Task 8

01Overview

This task plots a level over time. A vertical Slide control sets a value between 0 and 80, and a Waveform Chart draws that value as a line that moves across the screen while the program runs. A STOP button ends the program.

It is the first task that uses a chart, which is how LabVIEW shows a value changing with time. The VI is Task 4 waveform chart leveller.vi in the Labview Assignment.lvproj project.

02Concepts

Slide control

A numeric control the user moves up and down with the mouse. Here its scale runs from 0 to 80.

Waveform Chart

Adds each new value to the right-hand end of the plot, so the line scrolls like a live recording. The time axis counts samples and the chart keeps the latest 1024 points.

While Loop

Repeats until the stop condition is TRUE. Every pass of the loop adds one point to the chart.

Wait (ms)

Sets how often the loop runs. With 10 ms the loop runs about 100 times a second, so the chart gets about 100 points a second.

05Front Panel

The front panel has the Slide on the left, the Waveform Chart in the middle and the STOP button below. The chart’s time axis is at the bottom and its amplitude axis is on the left. The first screenshot shows the chart with a recorded trace, and the second shows it cleared with the slide at 0.

06Block Diagram

The whole program is one While Loop. Reading the diagram from left to right:

  1. The Slide control is wired through a tunnel on the left edge of the loop.
  2. Inside the loop, that wire goes to the Waveform Chart terminal, so the chart plots the slide value.
  3. A Wait (ms) function with the constant 10 sets the loop speed.
  4. The Stop button is wired to the stop terminal in the bottom-right corner, so pressing it ends the loop.

07Configuration

  1. Open Labview Assignment.lvproj and double-click Task 4 waveform chart leveller.vi.
  2. Set the Slide to the level you want to plot.
  3. Click the Run arrow in the toolbar and watch the line move across the chart.
  4. Click STOP to end the program.

08Evidence

Both windows are shown side by side, with the front panel on the left and the block diagram on the right. The first screenshot shows the chart with a recorded trace and the second shows the chart cleared with the slide at 0.

09Observations

  • The Slide is read only once per run — its terminal is outside the While Loop and the value enters through a tunnel, so it is read when the loop starts. Moving the slide during a run would not change the plot. Placing the Slide terminal inside the loop would make the chart follow it live.
  • The chart keeps its history between runs — in the first screenshot the time axis reads 21035 to 22058, while the cleared chart reads 0 to 1023. Old data from earlier runs can therefore appear on the plot until the chart is cleared.
  • The amplitude axis does not match the slide range — the chart shows 36 to 62 while the slide goes from 0 to 80, so values outside that window may not be visible unless autoscale is on.
  • The loop speed sets the chart speed — with a 10 ms wait the line scrolls quickly. A larger wait value would slow it down.

10Reflection

This task introduces the chart, one of the most common ways to show a measurement over time in LabVIEW. The same structure of a source value, a While Loop with a wait and a chart on the right is what the sensor tasks use to plot live data. It also shows why the position of a control matters: whether it is inside or outside the loop decides when its value is read.
