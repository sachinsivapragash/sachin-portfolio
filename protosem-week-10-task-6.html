MPU6050 Arduino Waveform Chart

← Week 10Task 1Task 2Task 3Task 4Task 5Task 6Task 7Task 8

01Overview

This task plots motion data from an MPU6050 sensor in real time. An Arduino Uno reads the sensor and sends the values to the computer over USB. The LabVIEW VI reads that text, cuts out the x, y and z values, converts them to numbers and plots them on three waveform charts, plus a fourth Merged Chart that shows all three together against time.

The VI is Task 5 mpu6050 arduino waveform chart.vi in the Labview Assignment.lvproj project. It builds on the serial reading from Task 4 and the charts from Task 5.

02Concepts

MPU6050

A motion sensor with an accelerometer and a gyroscope. The accelerometer measures acceleration along the x, y and z axes, and the gyroscope measures rotation around them.

Serial text parsing

The Arduino sends one line of text per reading. String Subset cuts out the characters for one value, and a string-to-number function turns them into a number.

Waveform Chart

Adds one new point per loop iteration, so each chart scrolls like a live recording of its axis.

Merge Signals

Combines the three numbers into one signal with three plots, so the Merged Chart can draw x, y and z together on a time axis.

05Arduino Sketch

The sketch starts the sensor and prints its readings to the serial port. The first lines are shown below, followed by a screenshot of the sketch and the Serial Monitor.

#include <Adafruit_MPU6050.h>
#include <Adafruit_Sensor.h>
#include <Wire.h>

Adafruit_MPU6050 mpu;

void setup(void) {
  Serial.begin(115200);

  // Try to initialize!
  if (!mpu.begin()) {
    Serial.println("Failed to find MPU6050 chip");
    while (1) {
      delay(10);
    }
  }
  Serial.println("MPU6050 Found!");

  // set accelerometer range to +-8G
  mpu.setAccelerometerRange(MPU6050_RANGE_8_G);

  // set gyro range to +- 500 deg/s
  mpu.setGyroRange(MPU6050_RANGE_500_DEG);
  • Serial.begin(115200) — sets the serial speed. The baud rate in LabVIEW must be the same.
  • mpu.begin() — starts the sensor. If it is not found, the sketch prints a message and waits.
  • setAccelerometerRange / setGyroRange — the accelerometer range is set to ±8 G and the gyroscope range to ±500 deg/s.

06Front Panel

The connection settings are on the left: the VISA resource name and the baud rate. The reading settings are in the top-right group: the three axis text boxes, byte count, milliseconds to wait, the read buffer and the stop button. The four charts are below: the x-axis, y-axis and z-axis charts and the Merged Chart, whose time axis shows the date and time.

07Block Diagram

The block diagram has the same structure as Task 4, with three parsing branches and four charts. Reading from left to right:

  1. The VISA resource name and baud rate are wired to VISA Configure Serial Port, and the connection passes into the While Loop through shift registers.
  2. Inside the loop, VISA Read reads up to byte count bytes into the read buffer, and a Wait (ms) function sets the loop speed.
  3. Three String Subset functions cut the text. Their constants are 16 and 4 for x, 26 and 4 for y, and 35 and 4 for z. Each result goes to its text indicator.
  4. Each piece of text is converted to a number and wired to its own chart (x-axis Chart, y-axis Chart and z-axis Chart).
  5. The three numbers also go into a Merge Signals function, which feeds the Merged Chart.
  6. The stop button ends the loop, and VISA Close on the right closes the serial port.

08Configuration

  1. Upload the MPU6050 sketch to the Arduino and leave it connected with the USB cable.
  2. Open Labview Assignment.lvproj and double-click Task 5 mpu6050 arduino waveform chart.vi.
  3. Choose the Arduino’s port in VISA resource name. In the test below it is COM6.
  4. Set baud rate to 115200 to match Serial.begin(115200).
  5. Set byte count and milliseconds to wait. The test below uses 200 and 100.
  6. Click Run and move the sensor. The four charts update.
  7. Click stop to end the program and close the port.

10Observations

  • The substring positions have to match the text format — the constants 16, 26 and 35 are fixed character positions. In the test run the read buffer holds comma-separated values (4.52,12.40,4.06,-0.38,-0.50,1.20,26.05), and the cut pieces are -0.3, 0,1. and .05. Only some of them are clean numbers, which is why the charts look spiky. Positions that match the sketch’s output exactly, or splitting the line at the commas, would give clean x, y and z traces.
  • The Serial Monitor shows a different format from the run — the Serial Monitor screenshot prints labelled lines such as Acceleration X: …, while the LabVIEW run reads a comma-separated line. The sketch and the LabVIEW positions need to describe the same format.
  • Baud rate must match the sketch — the front panel default is 9600 but the sketch uses 115200, so the baud rate was set to 115200 for the run.
  • The sketch file keeps an old name — the tab reads temphumiditylabviewtask3.ino, which is left over from the DHT11 task. A name such as mpu6050_labview.ino would be clearer.
  • The Merged Chart adds a time axis — it shows all three axes together with a date and time scale, which makes it easy to compare them.

11Reflection

This task combines the earlier ideas: reading serial data from an Arduino, turning text into numbers and plotting them on charts. It also shows that the LabVIEW program and the Arduino sketch are one system, because the character positions used to parse the text depend directly on what the sketch prints.

12Project Files

The VI is part of the Labview Assignment.lvproj project: Task 5 mpu6050 arduino waveform chart.vi. The Arduino sketch is temphumiditylabviewtask3.ino.

Task 6 is also built as a standalone Windows application, Task6.exe (about 212 KB), so it can run without opening the LabVIEW project. It needs the LabVIEW Run-Time Engine (64-bit) and, because it uses VISA serial functions, the NI-VISA runtime, with the Arduino connected to its COM port. Windows may show a security warning because the file is not digitally signed.
